# Coffee Delivery ☕

## 💻 Sobre o Projeto

O Coffee Delivery é uma aplicação web completa que simula um serviço de entrega de cafés especiais. A plataforma permite que os usuários explorem uma variedade de cafés, adicionem-nos ao carrinho, preencham um formulário de endereço de entrega, selecionem um método de pagamento e recebam a confirmação do pedido.

![coffe delivery](/public/coffe-delivery.png)

Este projeto foi desenvolvido utilizando tecnologias modernas de front-end, com foco em uma arquitetura de componentes, estilização avançada e uma experiência de usuário fluida e agradável.

## ✨ Funcionalidades Principais

- **Listagem de Cafés**: Uma página inicial que exibe uma variedade de cafés disponíveis para compra, com descrições, tags e preços.

- **Carrinho de Compras**: Os usuários podem adicionar e remover cafés do carrinho, além de ajustar a quantidade de cada item.

- **Formulário de Pedido**: Uma página de checkout onde o usuário pode preencher suas informações de endereço para a entrega.

- **Seleção de Pagamento**: Opções de método de pagamento, incluindo cartão de crédito, débito e dinheiro.
- **Confirmação de Pedido**: Uma tela de sucesso que exibe os detalhes do pedido e uma estimativa de entrega após a confirmação.

- **Roteamento**: Navegação entre as diferentes páginas da aplicação utilizando react-router-dom.

## Instalação e Execução

Para executar este projeto localmente, siga os passos abaixo:

Clone o repositório:

```Bash
git clone https://github.com/joserochadev/coffee-delivery.git
```

Navegue até o diretório do projeto:

```Bash
cd coffee-delivery
```

Instale as dependências:

```Bash
npm install -ci
```

Inicie o servidor de desenvolvimento:

```Bash
npm run dev
```
